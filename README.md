## 🚀 Was ist CMM?

**Code_Maker_Matrix (CMM)** ist eine **vollständig lokale, KI-gestützte Entwicklerzentrale**, die mit **Ollama** und deinen eigenen LLMs arbeitet – **100 % offline, keine Cloud, keine versteckten Kosten, DSGVO-konform.**

### 🌟 Die Features auf einen Blick

| Feature | Beschreibung |
|---------|--------------|
| 🤖 **KI-Assistent** | Chat, Code-Generierung, Analyse, Fixing, Optimierung, Erklärung, Umwandlung |
| 🤖 **Agenten-Modus** | 6 spezialisierte Subagenten (Explorer, Tester, Doc-Writer, Refactor, Bug-Hunter, Architekt) – parallel oder nacheinander |
| 🧱 **Legostein-Fabrik** | AST-Parser, Ampel-System, Abhängigkeits-Graph, Prompt-Generator |
| 🛠️ **Toolsammlung** | System-Check, Health-Check, Backup-Viewer, Prompt-Historie, Code-Statistiken mit Diagrammen |
| 🚀 **Projekt erstellen** | Komplette Projekte aus einer Idee generieren |
| 💾 **Zeitmaschine** | Backups, Sandbox, Panik-Knopf |
| 🔑 **Enterprise-Lizenz** | Key-Generator mit Ablaufdatum |
| 🧩 **CMM-Skills** | Benutzerdefinierte Workflows als YAML |
| 📦 **Git-Integration** | Status, Diff, Branches, Commit |
| 📂 **VS Code Export** | Projekte mit einem Klick öffnen |
| 🔗 **GitHub-Integration** | CMM präsentiert sich selbst aus dem Repository |
| 🧪 **2-Tage-Testlizenz** | Kostenlos testen – ohne Registrierung |

## 📦 Installation

```bash
# 1. Repository klonen
git clone https://github.com/GabelGold/Code_Maker_Matrix.git

# 2. In den Ordner wechseln
cd Code_Maker_Matrix

# 3. Abhängigkeiten installieren
pip install -r requirements.txt

# 4. Ollama starten
ollama serve

# 5. CMM starten
starte_dashboard.bat


📋 Systemvoraussetzungen
Windows 10/11

Python 3.10 oder höher

Ollama (lokal installiert)

📊 Erste Schritte
Projekt anlegen – In der Legostein-Fabrik auf "Neues Projekt anlegen"

Durchleuchten – Klick auf "Durchleuchten (AST-Scan)"

KI-Beschreibungen holen – Ollama erklärt dir deinen Code

Prompt generieren – Für Grok oder andere KIs

Code testen – In der Sandbox, bevor er ins Projekt kommt
